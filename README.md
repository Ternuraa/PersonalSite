# Lisa Savelieva — PersonalSite

Портфолио на Next.js (static export) → GitHub Pages.

## Локально

```bash
npm install
npm run dev
```

## Деплой

Пуш в `main` собирает сайт и публикует ветку `gh-pages`.

В репозитории: **Settings → Pages → Branch: `gh-pages` / `/ (root)`**.

Сайт: https://ternuraa.github.io/PersonalSite/
